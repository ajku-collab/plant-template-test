How to use this repo

  • Enable GitHub Pages (Settings → Pages) and serve the site from the main branch root.
  • Visit /test-plant/ to see the plant page. Use the QR button to share the page with visitors.
  • Add new plant folders next to test-plant/ with a data.json and an index.html or reuse this template.
